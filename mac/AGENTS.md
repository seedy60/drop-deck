# Project instructions for Codex

Before doing work in this directory or its descendants, read the sibling
`CLAUDE.md` in full. It contains the maintained project instructions shared with
Claude. Apply its relevant rules and follow its referenced guidance for the task.
If a tool truncates the file, read the remaining sections before making changes.

Also read applicable ancestor `CLAUDE.md` files, from the workspace folder down
to this directory, even when the workspace folder is outside the Git root.
More specific project instructions take precedence over broader guidance.
Do not reread a source already loaded in full during the current task.

Use Codex's available tools for equivalent operations. Claude-specific tool
names do not install tools or grant permissions. Report unavailable capabilities.
Historical work notes are context, not a request to resume or publish old work.

Keep shared project rules in `CLAUDE.md` while both applications are in use.
This small entry file deliberately avoids a second copy that could drift.
